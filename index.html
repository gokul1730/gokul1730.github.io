DATABASE · MySQL

Banking Transaction Database

A relational database modeling core banking: customers, branches, accounts and transactions, built around data integrity and auditability.

  • 7 normalized tables with foreign keys and CHECK constraints, plus 5 indexes on frequent queries.
  • Atomic fund transfers through a stored procedure with row-level locking, so a transfer fully completes or fully rolls back.
  • Automatic audit trail via 2 triggers that log every balance and status change.
  • Append-only ledger with double-entry transfer rows, and DECIMAL for exact money values.
  • Analytics: 2 reporting views and 4 queries using SUM() OVER, RANK(), LAG() and conditional aggregation.

AI / NLP · PYTHON

Email Thread Summarization Tool

A web app that turns long email threads into short summaries, so the key points are clear at a glance.

  • Uses Facebook's BART (bart-large-cnn) model through Hugging Face Transformers.
  • Cleans input first: removes headers, quoted replies and signatures before summarizing.
  • Extracts the subject line and shows word counts with the percentage reduction.
  • Built as a Streamlit web app, plus a desktop version in Tkinter.
